# 스킬 제안

> 이 파일은 `/analyze N` 실행 시 AI가 제안을 누적 추가합니다. 직접 편집해도 됩니다.

## 제안 목록

### 제안 #1 — 샷 라벨러 (Shot Labeler)
- **유형**: Claude Code 스킬
- **난이도**: 중급
- **관련 개념**: 샷 라벨링, 영상 메타데이터, 비전 모델
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_01_clatukim_submit]]
- **설명**: 영상 파일을 입력하면 자동으로 씬을 분할하고 각 샷에 대해 앵글(롱샷/미디엄/클로즈업), 구도(좌우 균형, 삼분할), 조명, 톤 등을 라벨링한다. 자동 라벨링 결과는 사람 검수용 마크다운 체크리스트로 출력 — "100% 자동" 대신 "사람 검수 시간을 80% 줄이는" 워크플로우.

### 제안 #2 — 전문가 콘텐츠 추출기 (BookToDataset)
- **유형**: CLI 도구
- **난이도**: 중급
- **관련 개념**: 전문가 지식 주입, 데이터셋 생성, 도메인 데이터화
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_01_clatukim_submit]]
- **설명**: 영화 이론 서적 PDF나 유튜브 자막을 입력하면 "샷 종류 → 정의 → 영화 예시" 형태의 구조화된 데이터셋(JSONL)으로 변환. 이번 주 도출된 "전문가 콘텐츠 → 초기 자동화 기반" 파이프라인의 첫 단계를 재사용 가능하게 만든다.

### 제안 #3 — 저작권 프리 미디어 검색기
- **유형**: Obsidian 플러그인
- **난이도**: 초급
- **관련 개념**: 저작권, 퍼블릭 도메인, 영상 소스
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_01_clatukim_submit]]
- **설명**: Obsidian 노트에서 키워드 선택 → CC0/퍼블릭 도메인 영상 데이터셋(Internet Archive, Pexels, Pixabay 등)을 한 번에 검색하고 결과를 노트에 인라인으로 박는다. 이번 주 회고에서 떠오른 저작권 이슈를 "찾기 귀찮아서 미루는" 단계에서 막아준다.

### 제안 #4 — 이론서 추출기 (FilmTheoryExtractor)
- **유형**: CLI 도구
- **난이도**: 고급
- **관련 개념**: 이론서 정전, Marker/Nougat 레이아웃 파싱, 그림-본문 정렬, 멀티모달 추출
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_02_clatukim_submit]]
- **설명**: 제안 #2의 BookToDataset를 한 단계 끌어올린 버전. 영화 이론서 PDF를 Marker/Nougat로 레이아웃 분리 → 본문·그림·캡션을 분리 추출 → "see Figure 4.12" 같은 참조를 자동으로 그림과 정렬 → Claude로 (technique, intents, examples, image_ref, source.book, page) 튜플 JSON 생성. 이번 주 설계의 Phase A를 그대로 도구화 — Tier 1 7권을 한 달 안에 처리하는 게 목표.

### 제안 #5 — 신뢰도 분기 라벨러 (ConfidenceRouter)
- **유형**: Claude Code 스킬
- **난이도**: 중급
- **관련 개념**: 신뢰도 분기, 능동학습, 골드셋, 인간 스팟체크
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_02_clatukim_submit]]
- **설명**: 제안 #1의 샷 라벨러에 신뢰도 점수를 결합한 라우터. 각 자동 라벨에 confidence(high/mid/low)를 붙여 ≥0.8은 자동 채택, 0.5~0.8은 인간 스팟체크 큐, <0.5는 능동학습 큐로 분기 → 마크다운 보고서로 출력. 이번 주 설계의 핵심인 "오류 누적 차단"을 가장 작은 단위로 검증 가능.

### 제안 #6 — 골드셋 큐레이터 (GoldsetCurator)
- **유형**: Obsidian 플러그인
- **난이도**: 초급
- **관련 개념**: 골드셋, 평가 지표, 인간 전문가 주석, 무결성 봉인
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_02_clatukim_submit]]
- **설명**: 50~100씬 골드셋을 vault 안에서 관리하는 플러그인. 씬당 (영화·타임코드·기대 라벨·근거 인용) 카드를 만들고, 자동 라벨러가 침범 못 하게 별도 폴더에 봉인 + git pre-commit hook으로 보호. 이번 주 가장 강조된 "골드셋 무결성 사수" 원칙을 실제로 강제한다.

### 제안 #7 — 1주 PoC 자동화 키트 (PoC-1Week)
- **유형**: Claude Code 스킬
- **난이도**: 중급
- **관련 개념**: PoC, in-context 학습, PySceneDetect, Go/No-Go 판정
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_02_clatukim_submit]]
- **설명**: 이번 주 설계 §9의 "1주일 PoC"를 하나의 스킬로 묶음 — Mercado 50샷 추출 → Claude in-context 주입 → 카사블랑카 1편 PySceneDetect 분할 → 30샷 자동 주석 → 정확도/신뢰도 분포 리포트 → Go/No-Go 의사결정 문서 자동 생성. 매 부트스트랩 반복마다 재실행 가능한 평가 하네스로 발전시킬 수 있다.
