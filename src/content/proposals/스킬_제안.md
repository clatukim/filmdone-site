# 스킬 제안

> 이 파일은 `/analyze N` 실행 시 AI가 제안을 누적 추가합니다. 직접 편집해도 됩니다.

## 제안 목록

### 제안 #1 — 샷 라벨러 (Shot Labeler)
- **유형**: Claude Code 스킬
- **난이도**: 중급
- **관련 개념**: 샷 라벨링, 영상 메타데이터, 비전 모델
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_01_clatukim_submit]]
- **설명**: 영상 파일을 입력하면 자동으로 씬을 분할하고 각 샷에 대해 앵글(롱샷/미디엄/클로즈업), 구도(좌우 균형, 삼분할), 조명, 톤 등을 라벨링한다. 자동 라벨링 결과는 사람 검수용 마크다운 체크리스트로 출력 — "100% 자동" 대신 "사람 검수 시간을 80% 줄이는" 워크플로우.

### 제안 #2 — 전문가 콘텐츠 추출기 (BookToDataset)
- **유형**: CLI 도구
- **난이도**: 중급
- **관련 개념**: 전문가 지식 주입, 데이터셋 생성, 도메인 데이터화
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_01_clatukim_submit]]
- **설명**: 영화 이론 서적 PDF나 유튜브 자막을 입력하면 "샷 종류 → 정의 → 영화 예시" 형태의 구조화된 데이터셋(JSONL)으로 변환. 이번 주 도출된 "전문가 콘텐츠 → 초기 자동화 기반" 파이프라인의 첫 단계를 재사용 가능하게 만든다.

### 제안 #3 — 저작권 프리 미디어 검색기
- **유형**: Obsidian 플러그인
- **난이도**: 초급
- **관련 개념**: 저작권, 퍼블릭 도메인, 영상 소스
- **추천 멤버**: clatukim
- **참고 wikilink**: [[Week_01_clatukim_submit]]
- **설명**: Obsidian 노트에서 키워드 선택 → CC0/퍼블릭 도메인 영상 데이터셋(Internet Archive, Pexels, Pixabay 등)을 한 번에 검색하고 결과를 노트에 인라인으로 박는다. 이번 주 회고에서 떠오른 저작권 이슈를 "찾기 귀찮아서 미루는" 단계에서 막아준다.
